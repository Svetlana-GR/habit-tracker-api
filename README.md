# Habit Tracker API

Умный трекер привычек на FastAPI. Сервис позволяет добавлять привычки, отмечать их выполнение и отслеживать серии (streak) без пропусков.

## Запуск локально

1.  **Клонировать репозиторий:**
    ```bash
    git clone https://github.com/Svetlana-GR/habit-tracker-api.git
    cd habit-tracker-api
    ```

2.  **Создать виртуальное окружение:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установить зависимости:**
    *Для обычного запуска:*
    ```bash
    pip install -r requirements.txt
    ```
    *Для разработки и запуска тестов:*
    ```bash
    pip install -r requirements-dev.txt
    ```

4.  **Запустить приложение:**
    ```bash
    uvicorn app_final:app --reload
    ```
    Откройте документацию и попробуйте API: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Переменные окружения

Приложение использует файл `.env` для настроек. Для примера используйте `.env.example`.

*   `MAX_DAILY_HABITS` — максимальное количество привычек, которые можно создать (по умолчанию: `5`).

## Автоматические тесты

В проекте используется `pytest` и `httpx` для тестирования эндпоинтов.

1.  Убедитесь, что установлены dev-зависимости: `pip install -r requirements-dev.txt`.
2.  Запустите тесты:
    ```bash
    python -m pytest -v
    ```
    *Ожидаемый результат: 4 проверки (PASSED).*

## Диагностика и локальная проверка

Если приложение не отвечает или работает некорректно:

1.  **Проверка работоспособности (Health Check):**
    Выполните команду в новом окне терминала:
    ```bash
    curl http://127.0.0.1:8000/health
    ```
    Ожидаемый ответ: `{"status": "healthy"}`

2.  **Проверка версии:**
    ```bash
    curl http://127.0.0.1:8000/version
    ```
    Ожидаемый ответ: `{"version": "1.0.0"}`

3.  **Просмотр логов (на сервере):**
    Если приложение запущено как служба `systemd` на Ubuntu, логи можно посмотреть командой:
    ```bash
    sudo journalctl -u habitapp -f
    ```
    Для выхода из просмотра логов нажмите `Control + C`.

4.  **Перезапуск приложения (на сервере):**
    ```bash
    sudo systemctl restart habitapp
    ```
