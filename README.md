## О приложении

**Habit Tracker API** — это REST-сервис для ведения личного трекера привычек. 
*   **Для кого:** Для пользователей, которые хотят формировать полезные привычки (спорт, чтение, языки) и отслеживать свою дисциплину с помощью математического алгоритма «серий» (streak).
*   **Что делает:** Позволяет создавать привычки, отмечать их выполнение в конкретные даты и автоматически вычисляет количество дней подряд без пропусков.

## Установка и запуск

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/Svetlana-GR/habit-tracker-api.git
    cd habit-tracker-api
    ```

2.  **Создание виртуального окружения:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установка зависимостей:**
    *Для запуска приложения:*
    ```bash
    pip install -r requirements.txt
    ```
    *Для разработки и тестов:*
    ```bash
    pip install -r requirements-dev.txt
    ```

4.  **Запуск приложения:**
    *В режиме разработки (с автоперезагрузкой):*
    ```bash
    uvicorn app_final:app --reload
    ```
    *Для обычной работы (production, без --reload):*
    ```bash
    uvicorn app_final:app --host 0.0.0.0 --port 8000
    ```
    Откройте интерактивную документацию Swagger по адресу: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## Переменные окружения

Приложение использует файл `.env` для настройки лимитов. В репозитории есть шаблон `.env.example`.

*   `MAX_DAILY_HABITS` — максимальное количество привычек, которые пользователь может создать за один день (по умолчанию: `5`).

## Тестирование (CI и локально)

В проекте используется `pytest` для проверки логики.

1.  **Локальный запуск:**
    Убедитесь, что установлены `requirements-dev.txt`.
    ```bash
    python -m pytest -v
    ```
    *Ожидаемый результат: 4 проверки (PASSED).*

2.  **Автоматическая проверка (GitHub Actions):**
    При каждом `push` тесты запускаются автоматически. Ссылка на последний успешный запуск находится во вкладке **Actions** в репозитории.

## Диагностика и проверка работоспособности

Этот раздел критически важен для эксплуатации сервиса на сервере.

1.  **Проверка /health и /version:**
    В новом окне терминала (не закрывая `uvicorn`) выполните:
    ```bash
    curl http://127.0.0.1:8000/health
    # Ожидаемый ответ: {"status": "healthy"}

    curl http://127.0.0.1:8000/version
    # Ожидаемый ответ: {"version": "1.0.0"}
    ```

2.  **Где смотреть логи:**
    *   **Локально:** Логи выводятся прямо в терминал, где запущен `uvicorn`. Ищите строки `[EVENT]`.
    *   **На сервере (Production):** Если приложение запущено через `systemd`, используйте команду:
        ```bash
        sudo journalctl -u habitapp -f
        ```
        *(Нажмите `Control + C` для выхода из просмотра логов).*

3.  **Перезапуск на сервере:**
    ```bash
    sudo systemctl restart habitapp
    ```
