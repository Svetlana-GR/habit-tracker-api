# Habit Tracker API

Умный трекер привычек на FastAPI.

## Запуск локально

1. Склонировать репозиторий
2. Создать окружение: `python3 -m venv venv`
3. Активировать: `source venv/bin/activate`
4. Установить зависимости: `pip install -r requirements.txt`
5. Запустить: `uvicorn app_final:app --reload`

Откройте [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
